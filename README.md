# Andrea Caputo Research Group

The group website is published at https://andrea0292.github.io/Andrea-Caputo-Lab/.

## Editing the group homepage

* Edit the text, people, selected papers, and teaching link in `layouts/lab/homepage.html`. Its Hugo type and layout are selected in `content/_index.md`.
* Homepage styles and illustrations live in `static/lab/`. The diagrams are original schematic illustrations, not measurements. The portrait is adapted from the existing author image in this repository.
* To keep the checked-in static copy in sync, copy the homepage to `public/index.html` and the assets from `static/lab/` to `public/lab/`. The static copy can be previewed directly in a browser.
* The remaining pages, CV, and downloads retain their previous paths. The existing Pages workflow builds the Hugo site on pushes to main.

The teaching button opens the shared Dropbox folder. Replacing documents in that folder does not require a website change.
